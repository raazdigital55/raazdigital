# RaaZ Digital — ড্যাশবোর্ডসহ সাইট (কোড না ছুঁয়েই প্রোডাক্ট ও কনটেন্ট বদলান)

## এটা কীভাবে কাজ করে (সহজ করে)
1. আপনি `আপনার-সাইট/admin/` এ গিয়ে ড্যাশবোর্ডে ঢোকেন এবং প্রোডাক্ট, দাম, ছবি বা ফোন নম্বর বদলে **Save** চাপেন।
2. ড্যাশবোর্ড আপনার GitHub-এ পরিবর্তনটা জমা রাখে।
3. Cloudflare নিজে থেকে সাইট আবার বানিয়ে নেয় (প্রায় ১–৩ মিনিট), আর নতুন সংস্করণ লাইভ হয়ে যায়।
প্রোডাক্ট বদলালে স্টোর, প্রতিটা প্রোডাক্টের SEO পেজ আর সাইটম্যাপ, সব একসাথে নিজে থেকে হালনাগাদ হয়।

**কোন CMS নিয়েছি:** Sveltia CMS। এটা Decap-এর মতোই (একই কনফিগ ফরম্যাট), ফ্রি, তবে Cloudflare-এ GitHub দিয়ে ঢোকা সহজ: একটা "পার্সোনাল অ্যাক্সেস টোকেন" দিয়েই ঢোকা যায়, আলাদা লগইন-সার্ভার বানাতে হয় না (Decap-এ হয়)। Strapi নেননি, কারণ ওটার জন্য সবসময় চালু একটা সার্ভার ও ডেটাবেস লাগে, ফ্রি Cloudflare Pages-এ চলে না।

⚠️ এতে আপনাকে **নতুন একটা Cloudflare Pages প্রজেক্ট** বানাতে হবে (Git-এর সাথে যুক্ত)। আগের "ড্র্যাগ-ড্রপ" প্রজেক্ট পরে Git-এ বদলানো যায় না। নতুনটা চালু হলে পুরোনোটা মুছে দিতে পারেন।

## ধাপ ১ — GitHub-এ ফাইল রাখুন (প্রায় ১০ মিনিট)
1. github.com এ ফ্রি অ্যাকাউন্ট খুলুন (থাকলে ঢুকুন)।
2. ডান উপরে **+** → **New repository**। নাম দিন `raazdigital-site`, **Private** রাখতে পারেন, **Create repository** চাপুন।
3. এই জিপটা আনজিপ করুন। পেজে **uploading an existing file** লিংকে চাপুন, তারপর আনজিপ করা ফোল্ডারের **ভেতরের সব ফাইল ও ফোল্ডার** টেনে ছেড়ে দিন (জিপ নয়, ফোল্ডারটাও নয়, ভেতরের জিনিসগুলো)।
4. নিচে **Commit changes** চাপুন। (ব্রাউজারে একবারে ১০০টা ফাইলের বেশি দেওয়া যায় না। আমাদের প্রায় ৮২টা, তাই চলবে। "too many files" দেখালে দুই ভাগে দিন।)

## ধাপ ২ — ড্যাশবোর্ডকে আপনার রিপোজিটরি চেনান (২ মিনিট)
1. GitHub-এ ফাইল `static/admin/config.yml` খুলুন, উপরের **✏️ (Edit)** চাপুন।
2. এই লাইনটা খুঁজুন: `repo: YOUR_GITHUB_USERNAME/raazdigital-site`
3. `YOUR_GITHUB_USERNAME` এর জায়গায় আপনার GitHub ইউজারনেম লিখুন, যেমন `repo: rahim123/raazdigital-site`।
4. **Commit changes** চাপুন।

## ধাপ ৩ — Cloudflare Pages-এ নতুন প্রজেক্ট (৫ মিনিট)
1. Cloudflare → **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**।
2. GitHub অনুমতি দিন, রিপোজিটরি `raazdigital-site` বেছে নিন → **Begin setup**।
3. প্রজেক্টের নাম দিন (আগেরটা `raazdigital` নিয়ে থাকলে নতুন নাম, যেমন `raazdigital-cms`)। Production branch: `main`।
4. **Framework preset: None**।
5. **Build command:** `npm install && python3 build.py`
6. **Build output directory:** `dist`
7. **Save and Deploy** চাপুন। ২–৩ মিনিট অপেক্ষা করুন। শেষে `https://আপনার-নাম.pages.dev` এ সাইট খুলবে।
   - Cloudflare-এর বিল্ড এনভায়রনমেন্টে Python 3.13 ও Node 22 আগে থেকেই থাকে। কখনো "python3 not found" এলে প্রজেক্টের Settings → Variables এ `PYTHON_VERSION` = `3.13` যোগ করুন।
8. সাইটের ঠিকানা `raazdigital.pages.dev` থেকে আলাদা হলে ধাপ ৬-এর পর ড্যাশবোর্ডের **Settings → Website address** এ আসল ঠিকানা বসান (সাইটম্যাপ ঠিক থাকবে)।

## ধাপ ৪ — GitHub টোকেন বানান (ড্যাশবোর্ডে ঢোকার চাবি, ৩ মিনিট)
1. GitHub → ডান উপরে আপনার ছবি → **Settings** → একদম নিচে **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**।
2. নাম: `RaaZ CMS`। Expiration: ৯০ দিন থেকে ১ বছর (ফোনে রিমাইন্ডার রাখুন, মেয়াদ শেষে নতুন বানাতে হবে)।
3. **Repository access → Only select repositories →** `raazdigital-site`।
4. **Permissions → Repository permissions → Contents: Read and write** বেছে নিন।
5. **Generate token** চাপুন এবং টোকেনটা **এখনই কপি করুন** (পরে আর দেখা যায় না)।
6. ⚠️ এই টোকেন আপনার রিপোজিটরির চাবি। কাউকে দেবেন না। হারালে GitHub-এ গিয়ে এটা **Revoke** করে নতুন বানান।

## ধাপ ৫ — ড্যাশবোর্ডে ঢুকুন
1. ব্রাউজারে খুলুন: `https://আপনার-সাইট/admin/`
2. টোকেন দিয়ে সাইন-ইনের অপশনটা বেছে নিন (**Sign in with token**, লেখাটা সামান্য আলাদা হতে পারে), ধাপ ৪-এর টোকেন পেস্ট করুন।
3. ঢুকলে বাঁ পাশে **Products** আর **Settings** দেখবেন। টোকেন শুধু আপনার ব্রাউজারে থাকে।
   - টোকেনে কোনো অনুমতির সমস্যা দেখালে, পর্দায় যে অনুমতির নাম লেখা থাকবে সেটা টোকেনে যোগ করুন।

## ধাপ ৬ — রোজকার কাজ
| কাজ | কীভাবে |
|---|---|
| **দাম বদলানো** | Products → প্রোডাক্ট খুলুন → Price বদলান → **Save** |
| **Shared / Private দাম** | প্রোডাক্টে **Plans** এ Add চাপুন: নাম `Shared · 1 Month` দাম `299`, আরেকটা `Private · 1 Month` দাম `699` (কম দাম আগে) |
| **নতুন প্রোডাক্ট** | Products → **New Product** → নাম, ক্যাটাগরি, দাম, বর্ণনা দিন → Save। স্টোরে ছবিসহ কার্ড, নিজস্ব SEO পেজ আর সাইটম্যাপ নিজে থেকে হয়ে যাবে |
| **নিজের ছবি দেওয়া** | প্রোডাক্টে **Picture** এ ছবি আপলোড করুন। না দিলে রঙিন টাইল নিজে থেকে বানানো হয় |
| **প্রোডাক্ট সরানো** | প্রোডাক্ট খুলে উপরে Delete |
| **ফোন, ঠিকানা, WhatsApp, পেমেন্ট নম্বর, ডলারের রেট** | **Settings** → **Phone, address, payment & more** |
| **Popular Picks বদলানো** | Settings → Popular Picks (প্রোডাক্টের নাম হুবহু লিখুন) |
| **কাজ লাইভ হলো কি না দেখা** | Cloudflare → প্রজেক্ট → **Deployments**, "Success" হলে সাইট রিফ্রেশ করুন |

**নিয়ম:**
- প্রোডাক্টের **নাম পরে বদলাবেন না**, কারণ নাম থেকেই পেজের ঠিকানা হয়, বদলালে আগের লিংক নষ্ট হবে।
- দুটো প্রোডাক্টের নাম একই হলে বিল্ড থামবে এবং লগে নাম দেখাবে।
- ক্যাটাগরির তালিকা `static/admin/config.yml` এ আছে। নতুন ক্যাটাগরি চাইলে ওখানে `options` এ লাইন যোগ করুন (সাইট নিজে থেকে নতুন ক্যাটাগরি দেখাবে)।
- প্রিভিউ নেই। Save করার ১–৩ মিনিট পরে লাইভ সাইটে দেখবেন।

## সমস্যা হলে
- **বিল্ড ব্যর্থ:** Cloudflare → Deployments → ব্যর্থ বিল্ডে চাপুন → লগের শেষ লাইন দেখুন। প্রায়ই কোনো প্রোডাক্টে নাম বা ক্যাটাগরি ফাঁকা, অথবা দুটো একই নাম।
- **ড্যাশবোর্ড ফাঁকা:** `static/admin/index.html` এ CMS-এর সংস্করণ (`0.211.2`) পিন করা আছে। প্রয়োজনে Sveltia-র সর্বশেষ সংস্করণ নম্বর বসিয়ে দেখুন।
- **শেয়ার ছবি (og.png) হচ্ছে না:** বিল্ড লগে `sharp` নিয়ে সতর্কবার্তা দেখাবে। সাইট ঠিকই চলবে, শুধু সোশ্যাল শেয়ারের ছবি বাদ যাবে।
- **একাধিক স্টাফ:** টোকেন পদ্ধতি একজন মালিকের জন্য ভালো। পরে অন্যদের "GitHub দিয়ে লগইন" লাগলে একটা ছোট Cloudflare লগইন-সার্ভিস বসাতে হবে, আমাকে বললে করে দেব।

## ফোল্ডারের ভেতরে কী আছে
- `content/products/*.json` — ৬৪টা প্রোডাক্ট (ড্যাশবোর্ড এগুলো বদলায়)
- `content/settings.json` — ফোন, ঠিকানা, পেমেন্ট নম্বর ইত্যাদি
- `static/admin/` — ড্যাশবোর্ড (`index.html`, `config.yml`)
- `static/images/` — ছবি (আপলোড করা ছবি `uploads/` এ জমে)
- `template/index.template.html` — সাইটের নকশা (এটা ড্যাশবোর্ড থেকে বদলায় না)
- `build.py`, `tools/` — সাইট বানানোর স্ক্রিপ্ট
